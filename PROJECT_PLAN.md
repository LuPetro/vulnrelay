# Project plan

- [ ] Phase 1: runnable foundation: API, configuration, SQLite, migrations, CLI, Docker, tests. Verify installation and container execution.
- [ ] Phase 2: NVD ingestion, CISA KEV and FIRST EPSS enrichment, durable checkpoints and provenance.
- [ ] Phase 3: assets, deterministic explainable rules, Telegram, durable retry queue and deduplication.
- [ ] Phase 4: optional local configuration UI.
- [ ] Phase 5: additional connectors and sources, version matching, digests.
- [ ] Phase 6: optional AI with safe fallback.
- [ ] Phase 7: release hardening, end-to-end verification and contributor documentation.

Completion requires independently verified delivery of relevant real CVEs and restart recovery; no phase is complete merely because scaffolding exists.
